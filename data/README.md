# Dataset

The original training notebook references the public [`tarteel-ai/everyayah`](https://huggingface.co/datasets/tarteel-ai/everyayah) dataset. Dataset files are not included in this repository because they are large and have their own hosting/distribution terms.

Review the dataset card and terms before downloading or using the data. The notebook selects a subset of parquet shards and creates train/test subsets; exact reproducibility may require recording the precise dataset revision and split used in the original run.
